Features

为分发而生

不止是一个群发工具，而是一层 AI 可调用的分发基础设施

01

官方 API · 零封号

B站、微信公众号全部走官方开放接口，不碰灰色 RPA 与模拟登录，账号安全是底线。

02

MCP Server · Agent 可调用

14 个开箱即用的 MCP 工具：创建内容、排期、发布、查询状态。你的 AI Agent 一句话就能完成一次全平台分发。

03

一次创作 · 多平台排期

写一篇，定时发往多个平台。发布时间、标题、封面可按平台单独微调。

04

AI 文案助手

输入主题，自动生成多个标题变体并打分，告别"标题想半小时"。

05

数据看板

发布成功率、各平台分发量、失败原因，一屏看清，分发效果有数可依。

06

私有化部署

Docker 一键启动，账号凭证加密存储，数据不出内网。企业版支持完全私有化。

How it works

三步，开始分发

STEP 01

连接账号

B站扫码 OAuth 授权，公众号填入 AppID / AppSecret。凭证加密保存，随时可解绑。

STEP 02

创作与排期

在调度台写好内容，或让 AI Agent 通过 MCP 传入。设定各平台的发布时间。

STEP 03

自动分发

到点自动投稿 / 群发，失败自动重试并通知。数据回流到看板。
